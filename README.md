# 奶娃 · 王冠夺还

一个单人 PVE 网页格斗竞技游戏：奶娃使用奶蛋范围爆破和苹果回旋投掷，穿过三章竞技场，击败首领并救回蛋小黄公主。另含无尽竞技模式。

手机使用屏幕摇杆和技能按钮；电脑使用 WASD / 方向键移动、J 连击、K 奶蛋、L 苹果、空格闪避、E 必杀。

`index.html` 是包含全部图片、界面与脚本的独立网页。不需要 Node.js、后端或游戏服务器。战绩仅保存在当前浏览器中。

## 发布

将此目录上传至公开 GitHub 仓库。Settings → Pages → Deploy from a branch → main / (root)，保存后等待 Pages 发布成功。`.nojekyll` 用于直接发布静态文件，无需构建配置。
